1 — Basic Form · מבנה טופס בסיסי

form = container לכל השדות. action = לאן נשלחים הנתונים. method = POST או GET. name = מפתח השדה ב-req.body (חייב על כל שדה).

2 — Input Types · סוגי שדות קלט

type קובע מה המשתמש מזין — ואיזו מקלדת המובייל פותח.

checkbox — אפשר לבחור אחד או יותר

radio — בחירה אחת מתוך קבוצה (אותו name)

3 — Labels · נגישות ו-UX

לחיצה על label מעבירה פוקוס לשדה. for + id חייבים להיות זהים.

שיטה 1 — label נפרד עם for + id

שיטה 2 — label עוטפת (נוח ל-checkbox / radio)

4 — Validation · בדיקות בדפדפן

Browser validation = שכבה ראשונה. תמיד בדוק שוב בשרת!

5 — GET vs POST · חיפוש מול שליחת מידע

טופס חיפוש — method="GET"

GET מתאים לחיפוש — הנתונים מופיעים ב-URL (?q=...)

טופס הרשמה — method="POST"

POST מתאים לשליחת מידע רגיש — הנתונים לא ב-URL

סיכום השיעור

מה למדנו היום?

  • form — action + method, container לכל השדות
  • input types — text, email, password, number, date, checkbox, radio
  • select + textarea — רשימה נפתחת וטקסט רב-שורות
  • label — for + id (או label עוטפת) — חובה לנגישות
  • validation — required, min/max, minlength/maxlength, pattern
  • GET vs POST — חיפוש ב-URL מול שליחת מידע לשרת
